# Security Policy

## Supported versions

Sonofin is pre-release software. Security fixes are applied to the current
`main` branch; no released version is currently supported.

Sonofin has not completed the security-hardening and deployment milestones in
its roadmap. Do not treat the current code as ready for an untrusted public,
multi-tenant deployment.

## Reporting a vulnerability

Private vulnerability reporting is not currently enabled for this repository.
Open the **Security contact request** issue form to ask the maintainer to
establish a private channel. That request is public, so do not describe the
vulnerability there. If GitHub's **Report a vulnerability** button is enabled
later, prefer that private flow.

Never submit passwords, Jellyfin or Sonos tokens, private keys, link codes,
household or device bindings, private server URLs, request bodies or headers,
server response bodies, database contents, or unsanitized logs. Use synthetic
placeholders and the minimum reproduction necessary.

Reports should state the affected commit, expected impact, sanitized
reproduction steps, and any suggested mitigation. Triage and response are
best-effort while the project remains pre-release.
